Schema Definitions & Foreign Key References

School

  • _id: sch_uuid
  • code: String (Unique)
  • timezone: String

AcademicTerm

  • _id: term_uuid
  • schoolId → School
  • academicYear, isCurrent

User

  • _id: usr_uuid
  • schoolId → School
  • role, email, block, ban

Guardian & Relation

  • _id: grd_uuid / sg_uuid
  • studentId → User
  • guardianId → Guardian

Class

  • _id: cls_uuid
  • schoolId → School
  • classTeacherId → User

Timetable

  • _id: tt_uuid
  • classId → Class
  • subjectId → Subject
  • teacherId → User
  • periodId → Period

StudentTest

  • _id: stt_uuid
  • assignmentId → Assignment
  • studentId → User
  • gradedBy → User

Invoice & Payment

  • _id: inv_uuid / pay_uuid
  • studentId → User
  • feeStructureId → FeeStructure
  • invoiceId → Invoice
